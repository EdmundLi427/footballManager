# ETL (Extract-Transform-Load)

Batch data processing pipelines for cleaning and standardizing NFL league data.

## Overview

This module contains Jupyter notebooks for exploratory data transformation and test scripts for validation. Raw data files are ingested, cleaned, and output to the `data/clean/` directory.

## Notebooks

- **`dataClean.ipynb`** — main ETL pipeline; reads raw CSVs from `data/raw/`, applies transformations (snake_case columns, null handling, deduplication), outputs cleaned CSVs to `data/clean/`
- **`testApi.ipynb`** — explores ESPN and other sports APIs for validation and reference data
- **`uploadToAzure.ipynb`** — helper for uploading processed data to Azure Storage (exploratory; not part of the automated pipeline)
- **`sleeper.ipynb`** — utilities and exploratory work (small notebook)

## Data Layout

- `data/raw/` — raw input CSVs (players, teams, schedules, rosters, games, standings, athletes)
- `data/clean/` — cleaned output CSVs from `dataClean.ipynb`

All CSV files are gitignored (large, regenerated by notebooks).

## Testing

Run validation tests with:

```bash
python etl/tests/test_clean.py
```

This script validates output from `dataClean.ipynb`:
- Row counts match expectations
- Required columns are present
- Null values follow documented patterns
- No unexpected duplicates

## Development Notes

Notebooks are exploratory; consider migrating stable ETL logic to Python modules if patterns solidify. Each notebook documents its data conventions at the top.

## Dependencies

Notebooks use:
- `pandas` — data manipulation
- `requests` — API calls
- `pytz` — timezone handling
- Standard library: `csv`, `json`, `pathlib`

Install via the workspace root: `uv sync`
